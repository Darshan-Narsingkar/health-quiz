# Health & Wellness Quiz

An interactive 10-question quiz covering nutrition, sleep, exercise, first aid, hygiene, and heart health. Built as a single-page HTML app with light/dark theme support.

## Live demo

Once GitHub Pages finishes deploying, the quiz will be live at:

**https://darshan-narsingkar.github.io/health-quiz/**

## Running locally

Just open `index.html` in any modern browser — no build step, no dependencies to install.

## Features

- 10 health & wellness multiple-choice questions
- Progress bar and one-at-a-time question flow
- Instant feedback with explanations after each answer
- Scored results screen with retake option
- Responsive layout that works on phone and desktop
- Automatic light/dark theme based on system preference
